# Spring Boot Employee Management API

A RESTful Employee Management API built using Spring Boot, Spring Data JPA, and MySQL.

This project is created for learning and practicing real-world Spring Boot backend development concepts such as REST APIs, layered architecture, DTOs, JPA, validation, and database integration.

---

## 🚀 Technologies Used

- Java
- Spring Boot
- Spring Web
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Jakarta Validation
- Git & GitHub
